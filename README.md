## 🧠 Two Generation Modes

### ⚡ Instant Mode

Instant Mode requires:

- No AI model download
- No API key
- No account
- No server-side AI

It uses lightweight client-side logic to generate social media content immediately.

This makes it suitable for smartphones and low-powered devices.

### 🧠 Local AI Mode

For users who want more advanced generation, Creator Studio can optionally use a local AI model through WebLLM and WebGPU.

The model is downloaded only when the user explicitly chooses Local AI.

Nothing is downloaded automatically when the tool opens.

## 🔐 Privacy

Creator Studio is designed with a browser-first approach.

Instant Mode does not require an account, API key or AI model download.

Local AI mode processes generation directly on the user's device after the model has been downloaded.
